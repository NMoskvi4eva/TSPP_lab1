Вміст каталогу: Концептуальний опис архітектури програмного продукту  

Архітектурний тип: Mobile Application (MA).
Рівні роботи:  

Presentation Level (PL): Інтерфейс на Android (Kotlin/Java).  

Business Level (BL): Сервер застосунків на базі Node.js для обробки логіки.  

Access Level (AL): Зберігання даних у форматі JSON (NoSQL MongoDB).
