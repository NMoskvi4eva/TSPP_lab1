### Аналіз інформаційних потреб

| Потреба | доступність | зрозумілість | цінність | актуальність |
| :--- | :--- | :--- | :--- | :--- |
| температура навколишнього середовища | повільно | - | - | запізно |
| психологічно-емоціональна стабільність | - | незрозуміло | - | - |
| повага оточуючих | неможливо | - | дорого | - |
| зацікавленість літературною прозою | - | - | - | запізно |

**Пояснення незадоволення:**
- Дані про зміну температури від датчиків надходять повільно та часто запізно для швидкого регулювання клімату.
- Методики підтримки емоційної стабільності часто описані надто складною термінологією (незрозуміло).
- Самостійно знайти спільноту для отримання визнання практично неможливо, а спеціалізовані заходи коштують дорого.
- Інформація про нові літературні надходження часто з'являється запізно.
